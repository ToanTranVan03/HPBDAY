# 🎉 Website Chúc Mừng Sinh Nhật (Happy Birthday Interactive Web)

Trang web chúc mừng sinh nhật tương tác cao, thiết kế theo phong cách Glassmorphism sang trọng, sử dụng Bootstrap 5, tích hợp đầy đủ âm nhạc và hiệu ứng pháo hoa, bong bóng, bánh kem 3D thổi nến.

## ✨ Tính năng nổi bật
- **Vinyl Record Player (Trình phát nhạc đĩa than)**: Tích hợp sẵn danh sách phát nhạc Happy Birthday piano, music box, fanfare và tiếng hiệu ứng SFX (mở quà, thổi nến, pháo hoa).
- **Hộp quà bí mật 3D**: Chạm để mở quà, tung confetti và popup chúc mừng.
- **Bánh sinh nhật 3D tương tác**: Chạm vào ngọn lửa để thổi nến chân thực, bốc khói và gửi ước nguyện tuổi mới.
- **Bức thư chúc mừng vintage**: Trang trí con dấu thư nghệ thuật, typography viết tay và lời chúc ý nghĩa.
- **Album kỷ niệm (Memories Carousel)**: Trình chiếu khoảnh khắc đẹp chuẩn Bootstrap 5.
- **Quẻ may mắn & Pháo hoa**: Rút quẻ thông điệp vũ trụ, đại tiệc pháo hoa đôi màn hình, thả bóng bay và tùy biến tên người nhận.

## 🚀 Cách chạy
Chỉ cần mở file `index.html` bằng bất kỳ trình duyệt nào (Chrome, Edge, Safari...) hoặc dùng Live Server / `python -m http.server 3000`.
